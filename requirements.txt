#  ⚠️  ABOUT "torch" (the reason this file works on EVERY computer)
#  ---------------------------------------------------------------
#  The AI Career Coach uses "sentence-transformers", which needs the
#  "torch" library. The normal PyPI version of torch bundles ~4 GB of
#  NVIDIA CUDA libraries that are ONLY useful if your computer has an
#  NVIDIA GPU. Most laptops do NOT.
#
#  →  setup.sh installs the lightweight CPU-only build of torch FIRST
#     (from PyTorch's official CPU index), and then installs this file.
#     Because torch is already installed, pip never downloads the
#     CUDA packages. No GPU? No problem — it all runs on CPU.
#
#  If you DO have an NVIDIA GPU and want to use it, just skip setup.sh
#  and run:  pip install torch
# ══════════════════════════════════════════════════════════════════
